SIGNAL // NOISE / @zakkster/lite-audio v2.2.0 / five scenes, real traces

Every phosphor trace on this page is actual signal - AnalyserNode waveforms, RMS meters, and the live PannerNode position all read straight off the engine's buses into pre-allocated Float32Arrays. Nothing here is drawn from a formula. The frame loop allocates nothing - even scene 5, which calls setPosition() every frame; the soak bar at the bottom proves it.

voice grid / one AudioPool per bus, capacity x 10 voices

Press and strafe across the grid to fire pooled voices - pointer events, so it works with mouse, trackpad or touch. Each cell is one channel: it lights while the voice sounds, and its generation counter ticks up every time that channel is re-issued. Overrun a bus and the oldest voice is stolen - the flash is the steal.

strafe the grid to issue handles

A voice handle is busIndex * 2^32 + poolHandle, and the pool handle is [gen:24][channel:8]. The first play on every bus is raw 0x00000000 - the bus tag above 32 bits is the only thing that keeps stop() from crossing wires. Click stop on a stale row: the generation no longer matches, so stop() is a silent no-op. That guard is the most interesting thing in the package, and it is usually invisible.

sidechain scope / music bus duckGain.gainrest 1.00

The DUCK button dips the music bus under a fast attack and lets it recover on a slow release - 0.05s vs 0.30s time constants. The dip is drawn cyan, the recovery amber: a duck that attacked and released at the same rate would sound like a mistake, and here you can see the asymmetry. AUTO arms duckOn(sfx, music) so firing the sting dips music on its own.

Volume and mute ride the bus's own gain; the duck rides a separate sidechain node, so a duck and a fader move compose instead of clobbering each other. Master mute persists under lite_audio_muted - the same key the old Howler manager used.

crossfade scope / xfadeGain per track + combined powerpower 0.00

Two gains and the power they sum to, sqrt(a^2 + b^2). The engine curves both sides on sin / cos, so the white line holds at 1.0 across the fade. A linear crossfade sags to 0.71 in the middle - the hole you would hear.

The A/B snapshots capture every bus's volume and mute as data, then morph the whole desk between them over the fade time - riding the same sidechain node the duck uses, so a snapshot applied mid-fade picks up from where the sound actually is. Fire a crossfade and hit A halfway: no click.

context lifecycle / ctxState() + isAutoSuspended()suspended

The engine unlocks on the first touchstart / mousedown / keydown at capture phase: silent-buffer pulse, resume(), flush the queue. This demo hands it a fake window so the one gesture you normally get is replayable. dormant is AU1's auto-suspend; interrupted is the iOS OS state - the simulate button walks it because a desktop context will not.

iOS enableAutoSuspend() on iOS: -

Arm auto-suspend, stop touching the page for four seconds, and the context suspends itself to stop the hardware spinning on silence - dormant lights amber. Any play() wakes it through the same unlock path, so it can never leave the page un-unlocked. On iOS that round-trip can demand a fresh gesture, so enableAutoSuspend() refuses there and returns false - the verdict on the right is read from a probe engine built with an iPhone user-agent.

Headphones on. A sonar source orbits your head; the engine writes its 3D position to a per-voice PannerNode through setPosition(handle, x, y, z) - a zero-alloc scratch stamp on this frame, flushed to the node on the shared ~10 Hz monitor. Toggle equalpower vs HRTF and listen: equalpower is amplitude-panned stereo, HRTF is per-voice binaural convolution - you should hear front/back and elevation, not just left/right. Drag the field to park the source dead-left, behind, or in front and confirm each on your rig.

retire Howler in one import

This engine ships a ./compat drop-in for the old lite-audio-manager. A game migrates by changing one line and removing a dependency - there is no Howler underneath.

- import { audioManager } from 'lite-audio-manager';
+ import { audioManager } from '@zakkster/lite-audio/compat';

- npm i lite-audio-manager howler
+ npm i @zakkster/lite-audio @zakkster/lite-signal @zakkster/lite-audio-pool

Every method is certified against a test in PARITY.md; the whole migration is MIGRATION.md.

zero-GC gate, on the page

Switch all five scenes 100 times and read the heap delta. A demo that allocates while displaying a heap graph is the worst possible advertisement, so this one does not. Chrome only - needs performance.memory; run with --enable-precise-memory-info for a tight number. The manual DevTools protocol is in DEMO-GATE.md.
